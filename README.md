# 모아

개인 메모를 기록하고 분류하는 메모장입니다.

## AI 탐색

**모든 메모** 화면 상단의 검색창 옆에서 **AI 탐색**을 누르면 탐색 입력란이 열립니다.
찾고 싶은 생각을 적고 **오른쪽 찾기 버튼**을 누르거나 약 0.7초 멈추면, 분류와 관계없이 텍스트가 있는 모든 메모에서
모든 후보를 의미가 가까운 순서로 정렬해 먼저 12개 보여줍니다. **더 보기**로 12개씩 추가할 수 있습니다.
결과는 데스크톱에서 한 줄에 4개, 넓은 화면에서는 6개씩 배치하며 제목과 한 줄 미리보기를 표시합니다.
결과를 누르면 편집 창으로 열리며,
탐색 문장은 그대로 유지됩니다. 같은 버튼을 다시 누르면 탐색 입력란이 닫힙니다.
다른 보관함이나 메모 쓰기로 이동하면 탐색을 멈추며, 모든 메모로 돌아오면 이어서 찾습니다.

메모 쓰기는 별도 화면에서 16줄의 넓은 본문 입력란을 사용하며, 아래로 크기를 조절할 수 있습니다.

- 첫 사용 시 AI 모델 약 120MB를 내려받습니다. 자동 분류와 같은 모델을 공유합니다.
- 검색용 분석은 브라우저의 Worker에서 실행됩니다. 기존 Firebase 메모 저장 방식은 유지됩니다.
- 각 메모의 제목·분류·본문에서 검색용 텍스트를 최대 1,000자 만듭니다. 의미 있는 텍스트가 있으면 긴 URL을 제외하며, 원래 메모는 수정하지 않습니다. 사진 내용은 분석하지 않습니다.
- 유사도 점수로 후보를 잘라내지 않습니다. 0.82 미만인 결과는 **참고 후보**로 구분하며, 이는 초기 표시 기준이고 확률이나 정확도 보장은 아닙니다. 실제 메모로 검색 품질을 평가해야 합니다.
- 분석 결과는 현재 페이지 메모리에만 캐시하며, 메모 수정·삭제 및 계정 전환 시 갱신하거나 해제합니다.

## 검사

Node.js 22 이상에서 실행합니다. 추가 패키지는 필요 없습니다.

```sh
node --test tests/related-notes.test.mjs
```

테스트는 순위·필터링, 탐색창의 검색 취소와 오래된 응답 처리, 한글 조합 입력,
계정 전환, 분석 캐시, 기존 자동 분류와의 모델 공유를 확인합니다.
실제 모델의 검색 품질과 브라우저 화면은 별도 확인이 필요합니다.

## 분류 관리

왼쪽 **분류** 제목 옆의 정렬 버튼에서 수동 정렬 창을 엽니다.
분류를 드래그하거나 위·아래 버튼으로 이동할 수 있으며, 고정된 분류는 항상 위에 모입니다.
같은 그룹(고정/일반) 안에서 순서를 바꿀 수 있습니다.

각 분류 옆 **⋯** 메뉴에서 **고정/고정 해제**, **이름 변경**을 사용합니다.
이름 변경은 그 분류를 가진 메모 전체에 적용되며, 중복된 분류 이름은 허용하지 않습니다.
모바일에서는 보관함·분류 목록의 **분류 관리** 버튼으로 같은 기능을 사용할 수 있습니다.

순서와 고정 상태는 계정별로 현재 브라우저에 저장되며 기기 간 동기화와 JSON 백업에는 포함되지 않습니다.
분류 이름은 메모와 함께 Firebase에 저장됩니다.
여러 메모의 이름 변경은 최신 태그를 읽는 트랜잭션으로 나누어 처리합니다.
일부 처리 후 실패하면 완료된 메모 수를 안내하며, 이전 분류에서 남은 메모를 다시 변경할 수 있습니다.

분류 관련 테스트: `node --test tests/categories.test.mjs`
