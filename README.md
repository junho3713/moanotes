# 모아

개인 메모를 기록하고 분류하는 메모장입니다.

## 관련 메모

메모 쓰기 화면 아래에서 **관련 메모 찾기**를 켠 뒤 생각을 적어 보세요.
입력을 약 0.7초 멈추면 기존 분류와 관계없이 텍스트가 있는 모든 메모에서
의미가 가까운 메모를 최대 3개 보여줍니다. 결과를 누르면 편집 창으로 열리며,
작성 중이던 새 메모는 그대로 유지됩니다. 버튼을 다시 누르면 검색을 끕니다.

- 첫 사용 시 AI 모델 약 120MB를 내려받습니다. 자동 분류와 같은 모델을 공유합니다.
- 검색용 분석은 브라우저의 Worker에서 실행됩니다. 기존 Firebase 메모 저장 방식은 유지됩니다.
- 각 메모의 제목과 본문 앞 1,000자를 비교합니다. 사진 내용은 분석하지 않습니다.
- 결과는 유사도 기준을 통과한 메모만 표시합니다. 기준값 0.82는 초기 휴리스틱이며, 실제 메모로 정확도를 평가하고 조정해야 합니다.
- 분석 결과는 현재 페이지 메모리에만 캐시하며, 메모 수정·삭제 및 계정 전환 시 갱신하거나 해제합니다.

## 검사

Node.js 22 이상에서 실행합니다. 추가 패키지는 필요 없습니다.

```sh
node --test tests/related-notes.test.mjs
```

테스트는 순위·필터링, 작성창의 검색 취소와 오래된 응답 처리, 한글 조합 입력,
계정 전환, 분석 캐시, 기존 자동 분류와의 모델 공유를 확인합니다.
실제 모델의 검색 품질과 브라우저 화면은 별도 확인이 필요합니다.
